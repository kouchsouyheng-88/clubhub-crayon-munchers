# Club Hub Retention Rules

| Field | Trigger | Action | Who or what runs it | How to verify |
|---|---|---|---|---|
| Student ID | After graduation | Delete | IT Admin |  Query database |
| Name | After graduation | Delete | IT Admin |  Query database |
| Email | After graduation | Delete | IT Admin |  Query database |
| Phone | Student withdraws SMS consent, or 6 months after graduation | Delete | IT Admin |  Query  database |
| Club membership | Student leaves a club or the club closes | Delete | Club leader, Administrator |  Query database |
| Attendance records | Identified attendance records reach 12 months | Aggregate | Organizer, Administrator |  Query database |
